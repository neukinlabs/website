HELIX 1

Compute at the core. Open protocols at the edge.

Helix 1 is a compute carrier board. Gigabit Ethernet API on the host side. COTS or custom I/O daughtercards connected via DIN 41612 Type C connector. Multiplexed GPIOs support digital and analog I/O, SPI, CAN, PWM, and more.

Test system configuration as code. Tests as code. Access raw GPIOs and peripherals through a minimal software stack you download on GitHub. Fewer abstractions with more control. No GUI required.

Need more I/O? Network multiple Helix 1s in a leader/follower configuration. Gigabit Ethernet carrier-to-carrier backbone with gPTP synchronization and Time-Sensitive Networking (TSN) for bounded latency communication. Scale I/O without redesigning the test system.
